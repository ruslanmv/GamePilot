## The 30-second pitch

GamePilot is an AI gaming buddy that:

- ✨ Watches your screen.
- 🎮 Hands the controller back the second you ask (Ctrl + Shift + Esc).
- 🍕 Lets the AI handle the boring parts — grinding, AFK survival, stuck boss fights.
- 🚨 Refuses to touch multiplayer. By design. Because we don't want you banned.

## The 30-second install

In a terminal, in the project folder:

```
make install
make start
make stop
```

Three commands. That's the whole flow. Details in [INSTALL_FOR_GAMERS.md](INSTALL_FOR_GAMERS.md).

## If you only remember one thing

**Ctrl + Shift + Esc** — the kill switch. Always armed. No matter what AI is doing.

If a session ever feels weird, hit it. We'd rather you bail mid-fight than lose your save, your account, or your trust.

## Brand voice (so the docs sound consistent)

- Gamer, not corporate. "You," not "users."
- Short sentences. Stacked.
- Slang allowed when it lands. Forced slang is cringe.
- Emojis only as bullet anchors in lists. Never as decoration. Never in buttons.
- Numbers are facts. "847k playing" beats "extremely popular."

If you're writing a doc here, match that voice. It's the brand.
