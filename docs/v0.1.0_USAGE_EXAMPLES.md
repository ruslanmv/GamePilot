## 🤖 Companion Chat Examples

### Example 1: Basic Advice

**Request:**
```python
import requests

response = requests.post("http://localhost:8000/companion/chat", json={
    "message": "What should I do?",
    "game_state": {
        "hp": 100,
        "enemy_near": False,
        "loot_visible": False
    }
})

print(response.json()["response"])
```

**Response:**
```
"With full health and no immediate threats, this is a good time to:

• Explore nearby areas for resources
• Build or improve your shelter
• Prepare for nightfall
• Check if you have enough food/supplies

What's your current objective?"
```

## 🐍 Python SDK Usage

### Direct Python Usage

```python
from gamepilot.app.companion import create_companion, parse_intent
from gamepilot.app.domains.construction import ConstructionPlanner

# Create companion
companion = create_companion(
    provider="openai",
    api_key="sk-...",
    model="gpt-4"
)

# Chat
response = companion.chat(
    user_message="How do I survive the night?",
    game_state={"hp": 50, "enemy_near": True}
)
print(response)

# Parse intent
parsed = parse_intent("build a stone tower")
print(f"Intent: {parsed.intent.value}")
print(f"Entities: {parsed.entities}")

# Construction planning
planner = ConstructionPlanner()
plan = planner.plan("tower", "stone")
print(f"Steps: {len(plan.steps)}")
print(f"Resources: {plan.total_resources}")
```

## 🎯 Complete Workflow Example

### Scenario: Player asks for help building

```python
import requests

API = "http://localhost:8000"

# 1. User sends message
user_message = "I want to build a safe base, I have wood and stone"

# 2. Parse intent
intent_response = requests.post(f"{API}/intent/parse", json={
    "text": user_message
})
intent = intent_response.json()
print(f"Detected intent: {intent['intent']}")  # "build"

# 3. Get construction plan
if intent["intent"] == "build":
    plan_response = requests.post(f"{API}/construction/plan", json={
        "structure_type": intent["entities"].get("structure", "simple_house"),
        "material": "stone"  # Prioritize stronger material
    })
    plan = plan_response.json()
    print(f"\nBuilding plan:")
    print(f"  - Structure: {plan['structure_type']}")
    print(f"  - Resources needed: {plan['total_resources']}")
    print(f"  - Time: {plan['estimated_time_minutes']} min")

# 4. Get companion advice
chat_response = requests.post(f"{API}/companion/chat", json={
    "message": user_message,
    "game_state": {"hp": 100, "enemy_near": False},
    "context": {"inventory": ["wood", "stone"]}
})
advice = chat_response.json()
print(f"\nCompanion advice:\n{advice['response']}")

# 5. Display to user
print("\n" + "="*60)
print("GAMEPILOT RESPONSE:")
print("="*60)
print(advice['response'])
print(f"\nResources: {plan['total_resources']}")
print(f"Time: {plan['estimated_time_minutes']} minutes")
```
