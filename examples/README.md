# Sample Video Placeholder

This directory should contain a sample gameplay video for demo mode.

## How to add a sample video:

1. Record 10-30 seconds of gameplay from any game
2. Save as `sample.mp4` in this directory
3. Test with: `gamepilot demo --video examples/sample.mp4`

## Or use a test video:

Download a free gameplay video from:
- YouTube (using yt-dlp)
- Free stock video sites
- Your own gameplay recordings

The video should be:
- MP4 format
- 720p or higher resolution
- Clear UI elements visible
- 10-60 seconds duration
